## How To Add Feedback

Prefer GitHub issues for actionable work. This wall is for recurring themes
that appear across multiple comments, issues, or reading-club sessions.

When a theme becomes actionable, use `community/reader-feedback-triage.md` to
map it to one chapter, one source-backed rewrite decision, and one validation
run.
